# 回訪小幫手：安裝步驟（約 10 分鐘，只要做一次）

架構：畫面放在 **GitHub Pages**（`docs/`），資料還是在你的「客戶回訪表」，中間由 **Apps Script**（`apps-script/Code.gs`）當資料 API。

## 1. 更新 Apps Script
1. 用電腦打開「客戶回訪表」→ **擴充功能 → Apps Script**（就是原本的「回訪小幫手」專案）。
2. `Code.gs`：內容全部刪掉，貼上 repo 裡 `apps-script/Code.gs`。
3. 左邊的 `Index.html` 不再需要：按旁邊 ⋮ → 刪除。
4. 左邊齒輪 **專案設定** → 勾「在編輯器中顯示 appsscript.json」→ 回編輯器打開 `appsscript.json`，貼上 repo 裡 `apps-script/appsscript.json`。
5. 💾 儲存。

## 2. 執行一次 setup（產生 App 密碼）
1. 上方函式下拉選 `setup`，按 **執行**（有授權視窗就允許）。
2. 下方「執行記錄」會顯示 **App 密碼**，先複製起來。之後也可以在 **專案設定 → 指令碼屬性 → API_TOKEN** 查到。

## 3. 部署成資料 API
1. **部署 → 管理部署作業 → 編輯（鉛筆）**（沒有舊的就「新增部署作業」→ 齒輪選 **網頁應用程式**）。
2. 版本：**新版本**；執行身分：**我**；誰可以存取：**所有人**。
   （「所有人」是讓 GitHub Pages 連得到；沒有 App 密碼的人什麼都讀不到。）
3. 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）。

## 4. 開啟 GitHub Pages
1. GitHub repo → **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/docs** → Save。
3. 約 1 分鐘後網址會是 `https://paulwu722.github.io/line-followup-helper/`。

## 5. 手機打開
1. 手機用 Safari / Chrome 打開上面的網址。
2. 第一次會跳出「連接試算表」：貼上第 3 步的網址和第 2 步的 App 密碼 → 連接。
3. Safari 按分享 → **加入主畫面**，會有綠色對話框圖示，就像一個 App。
4. 想換網址或密碼：按右上角 ⚙。

## 6.（選用）Email 提醒附上 App 連結
Apps Script → 專案設定 → 指令碼屬性 → 新增 `APP_URL` = 你的 GitHub Pages 網址。每天 8 點的提醒信就會附上連結。

## 怎麼用
- **今日待辦**：今天到期或逾期的人。按「傳 LINE」先寫訊息（上方顯示上次記下的「下次要提的事」），再打開 LINE 傳送。傳完按「已聯絡」，那個人馬上移到「等待回覆中」。
- **等待回覆中**：對方回了按「已回覆」填聊了什麼、下次要提的事、狀態（或用 Claude 的 line-chat-followup-log skill 記好後按「已上傳截圖」）；沒回按「沒反應」。
- **總名單**：依身份分四欄，依聯絡次數排序。
- **＋**：新增名單。

## 為什麼變快了
- 打開時先顯示手機上記住的資料，背景再更新（右上角顯示「同步中…」）。
- 按按鈕畫面立刻改，寫入試算表在背景排隊做；沒存到會跳提示並還原。
- 一次請求拿回全部資料，Apps Script 只讀兩次試算表。

## 之後想改
- 改了 `Code.gs`：貼上後 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不變。
- 改了 `docs/` 的畫面：推到 GitHub 的 main，Pages 約 1 分鐘自動更新。
- 換密碼：執行 `resetToken`，手機按 ⚙ 重新輸入。
